## Paleta de cores sugerida

| Cor | HEX | Uso | Sensação |
|---|---|---|---|
| Verde-musgo | `#4A6B4A` | header, rodapé, botões | natureza, calma, cultura |
| Mostarda | `#D4A23A` | preços, chamadas, hover | aconchego, atenção |
| Off-white | `#F5F1E8` | fundo das seções | leveza, papel, leitura |
| Grafite | `#2B2B2B` | títulos e corpo de texto | seriedade, legibilidade |
| Branco | `#FFFFFF` | respiro, separadores | limpeza, contraste |
